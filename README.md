# Eugene Airport Android releases

Public APK downloads and update metadata for the unofficial Eugene Airport Android
app. The application source code is maintained separately in a private repository.

## Install the latest version

1. On your Android phone, open the
   [latest release](https://github.com/Brusko25/Eugene-Airport-Releases/releases/latest).
2. Expand **Assets** and download the file ending in `.apk`.
3. Open the downloaded file and approve Android's installation prompt.

Android may ask you to allow installs from the browser or file manager you used. These
are debug-signed testing builds rather than Google Play releases.

Once version 0.6.0 or newer is installed, the app can check this repository from
**Settings → App updates** and link directly to newer APKs.

> This is an unofficial prototype. Always confirm flight information with your airline.
