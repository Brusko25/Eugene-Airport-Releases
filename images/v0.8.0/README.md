# Screenshot sources

Screenshots from EUG Airport 0.8.0 running in an Android emulator. Flight details, times and menu prices reflect the captured screen and can change.

Captured on 2026-09-13 using Android screencap from the installed version 0.8.0 on the Pixel 8a emulator.

- `departures.png`: Departure board with destinations, times, gates and flight status.
- `arrivals.png`: Arrival board with origins, times, gates and flight status.
- `airport-guide.png`: Airport guide with dining, parking, transport and accessibility.
- `dining.png`: Airport dining with cafe choices and breakfast menu.
